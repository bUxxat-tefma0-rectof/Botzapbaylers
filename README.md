# 🤖 DOGUINHA STORE

Bot WhatsApp para vendas + Painel Admin no Telegram

---

## 📱 COMO CRIAR PELO CELULAR

### 1. GITHUB
- Crie repositório no GitHub
- Faça upload de todos os arquivos

### 2. RENDER
- Conecte o repositório
- Build Command: `npm install`
- Start Command: `npm start`
- Adicione as variáveis do `.env`

### 3. CONECTAR WHATSAPP
- Após deploy, veja os logs
- Aparecerá o código de pareamento
- Conecte no WhatsApp

### 4. ACESSAR PAINEL ADMIN
- Abra o Telegram
- Envie `/admin` para o bot admin

---

## ⚙️ CONFIGURAÇÕES

Todas as configurações são feitas pelo painel admin no Telegram:
- Produtos e preços
- Estoques
- Mensagens
- PIX
- Afiliados
- Usuários
- Transmissões
